# 旅游平台界面全面焕新 + 路线规划增强（自定义出发地）

## 现状结论（探索发现）
- **配色撞车（最大病灶）**：品牌色为青绿 `#1CB89D→#0D9488` 渐变，但 Element Plus 主题未接管，约 20 处 `type="primary"` 按钮/dropdown/分页仍是默认蓝 `#409EFF`；同一青色渐变以行内样式复制了 **45 次**
- `tailwind.config.js` 的 brand/ocean/warm 色板定义后**零引用**（死配置）
- 首页 Hero 只有纯 CSS 渐变，全站无一张本地图片；空状态用 Element 默认灰插画
- 路线卡是纯文字卡，与景点卡/攻略卡风格断裂；三卡 hover 幅度不一致
- 加载三套并存（fa-spinner 转圈 / v-loading / 无骨架屏），`el-skeleton` 零使用
- 用户端 600px 以下导航直接隐藏，**移动端无法导航**
- 后台背景色 #F4F7FC 与用户端 #F8FAFC 不统一，后台无响应式

---

## 一、设计系统统一（治本，一处改全站生效）

**`src/assets/css/main.css`**：
1. `:root` 覆盖 Element Plus 主题变量：`--el-color-primary` 及 `light-3/5/7/8/9`、`dark-2` 全套映射为青绿色系 → 全站约 20 处默认蓝按钮、下拉、单选、分页、开关**自动变品牌青**（含全部后台管理页）
2. 定义品牌 CSS 变量（`--brand-500/--brand-600/--brand-gradient` 等）+ 全局工具类 `.brand-gradient`、`.btn-brand`、`.card`，替换散落 45 处的内联渐变
3. 统一 el-dialog/message/notification 与品牌风格一致；背景色统一为 `#F8FAFC`

**`tailwind.config.js`**：清理死配置，ocean 青绿色板设为主色系，更新 boxShadow 层级

## 二、用户端界面焕新

1. **首页 Hero 配图化**（`Home.vue`）：新增内置 SVG 风景插画（青绿色调层叠山川/云/飞鸟，离线可用、无版权问题）作为装饰层；热门景点封面图以轮播/拼贴形式融入 Hero 背景 + 深色遮罩，封面缺失时优雅降级到 SVG 插画；搜索区与统计数字样式升级
2. **卡片统一**：`RouteCard.vue` 增加品牌渐变头图区（大号交通方式图标 + 起终点视觉），补齐与 SpotCard/GuideCard 的视觉层次；三卡 hover 统一（-6px + 同一阴影 token）；`GuideCard` 固定 180px 高改为自适应防截断
3. **骨架屏**：新建 `SkeletonGrid.vue`（卡片型 el-skeleton），替换 Home/SpotDetail/RouteDetail/个人中心等页面的 fa-spinner 转圈；列表页统一 v-loading + 骨架
4. **空状态定制**（`EmptyState.vue`）：Element 默认灰线稿插画换为品牌风 SVG 插画
5. **移动端导航**（`UserLayout.vue`）：≤900px 显示汉堡按钮，展开抽屉式导航（含搜索、发布、消息入口），修复移动端不可导航问题
6. **登录/注册页品牌化**（`Login.vue`/`Register.vue`）：左右分栏布局，左侧品牌视觉区（SVG 风景插画 + 标语），右侧表单，替换现有单卡片样式
7. **列表/详情页打磨**：列表页筛选栏、分页区样式统一；详情页（SpotDetail/GuideDetail/RouteDetail）信息层级与图片失败占位优化

## 三、管理后台焕新

1. `MainLayout.vue`：内联样式收敛为 token；侧栏菜单视觉升级（更清晰的 active 态/图标层次）；增加响应式（窄屏侧栏可折叠）
2. `Dashboard.vue`：统计卡重设计（品牌渐变图标底 + 数值层次），ECharts 环形图配色统一为品牌青绿色系
3. 全部管理页按钮/弹窗/分页由第一步主题接管自动修正，另做统一页头/表格细节微调

## 四、功能：路线规划增强 —— 自定义出发地（核心）

**`RoutePlanner.vue`** 新增出发地设置区，4 种设定方式：
1. 从已选景点中快捷指定起点
2. 「我的位置」：`AMap.Geolocation` 插件一键定位
3. 地图点选：点击地图任意位置设为出发地（`AMap.Geocoder` 逆地理编码显示地名）
4. 搜索地点：`AMap.PlaceSearch` 关键字搜索选点

配套改动：
- **手动排序面板**：已选景点有序列表，支持拖拽排序（原生 HTML5 drag）+ 上移/下移按钮 + 移除；新增「自动排序」开关（关闭后不再自动重排）
- **`routePlanner.js`**：`planRouteOrder` 支持外部起点坐标（出发地不在景点列表时也能最近邻排序）
- **`ScenicMap.vue`**：新增 `startPoint` prop——渲染区别于景点的起点旗帜标记；驾车规划以起点为 search 起点（景点转为途经点）；高铁/火车/飞机估算从起点起算；总里程/耗时含出发点
- **导出行程**：一键复制/下载行程文本（编号站点、分段里程耗时、总计），纯前端无后端改动

## 五、验证方式
- `npm run build` 确认无编译错误；`npm run dev` 启动后用浏览器实测首页/列表/详情/规划/后台各页截图检查（后端未启动时验证降级态不白屏）
- 移动端宽度（600px/900px）验证导航抽屉与栅格降级
- 路线规划功能：验证 4 种出发地设定 + 手动拖拽排序 + 自动排序开关 + 导航规划结果正确性
